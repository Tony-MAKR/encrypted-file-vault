加密文件管理系统 - 桌面客户端安装说明

1. 安装版：运行 EncryptedFileVault-Setup-*.exe，按提示完成安装。
   免安装版：解压 EncryptedFileVault-Portable-*.zip 后运行其中的程序。

2. 安装包没有购买代码签名证书，Windows 可能提示“未知发布者”。
   请先用 SHA256SUMS.txt 核对文件校验值，再决定是否运行。

3. 首次启动填写服务器地址，默认 http://127.0.0.1:8000。
   请先在运行服务器的主机上启动 scripts\start.ps1。

4. 客户端不保存登录密码、主密码或密钥，也不复制数据库和密文。

5. 卸载客户端不会删除服务器上的数据库、密钥、密文或备份。

6. 升级时下载新的安装包覆盖安装；升级前建议先备份服务器数据。
   覆盖安装会保留服务器地址设置。

7. 系统要求：Windows 10/11 x64。客户端必须能访问服务器地址。
