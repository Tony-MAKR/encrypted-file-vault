# v1.0.0 发布说明

这是加密文件管理系统的首个公开版本。

## 亮点

这是第一个完整版本，包含 Windows 桌面客户端和网页端：

- 管理员/普通用户、用户组、按组授权和按人授权。
- 文字秘密和文件加密存储；AES-256-GCM 信封加密，主密码不保存。
- 文件边接收边加密，不在磁盘生成明文临时文件。
- 分类、标签、搜索、筛选、主页统计和密码生成器。
- 归档、所有权转移、30 天回收站和永久删除。
- 可查询审计日志，关键操作留痕且不记录秘密。
- 加密备份包、独立备份口令、备份验证和命令行恢复。
- 审计保留清理和只读部署安全检查。
- Windows 安装包、免安装包和 SHA-256 校验。

## 安装

系统要求：Windows 10/11 x64。

1. 先在运行服务器的主机上运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start.ps1
```

2. 运行安装包，或解压免安装包后启动。
3. 首次打开填写服务器地址，默认 `http://127.0.0.1:8000`，测试连接后保存。
4. 全新数据库会显示“创建第一位管理员”页面。

安装包**没有代码签名**，Windows SmartScreen 可能提示“未知发布者”。请先核对下面的 SHA-256，再决定是否运行。

## 安全说明

- 第一版是服务器端加密，不防御拥有服务器最高权限的恶意管理员。
- 主密码和备份口令都不会保存；丢失后无法恢复。
- 元数据（标题、说明、分类、标签）保持明文。
- 默认只监听 `127.0.0.1`，未开放局域网或公网。
- 被授权用户解密后可以拍照、另存或转发；系统只能降低风险，不能绝对阻止。
- 详细说明见 [SECURITY.md](../SECURITY.md)。

## 已知限制

- 安装包未签名，SmartScreen 可能提示未知发布者。
- 没有自动更新；升级需要手动下载安装包覆盖安装。
- 没有局域网/HTTPS 部署配置、双因素认证、密码历史或在线预览。
- 备份恢复只支持命令行，不提供网页一键恢复。

## 升级与回滚

- 从旧版本升级：先备份服务器数据，再覆盖安装客户端；服务器地址设置会保留。
- 回滚客户端：重新安装上一版本安装包；服务器数据不变。
- 回滚数据：使用 `scripts/restore-backup.ps1` 和最近一次加密备份。
